# A/B Testing & Experiment Analysis

*Created by Ritu raj Singh*

## Project Overview

This project analyzes an A/B experiment by comparing *Control* and *Treatment* groups to determine whether the observed difference in conversion performance is statistically significant.

## Tools Used

* Excel – Data Cleaning
* Python – Data Analysis & Statistical Testing
* Pandas & NumPy – Data Processing
* SciPy & Statsmodels – Hypothesis Testing
* Tableau – Visualization & Dashboard
* GitHub – Project Documentation

## Project Workflow

*Raw Data → Data Cleaning → Python Analysis → Hypothesis Testing → Tableau Visualization → Dashboard → Business Recommendation*

## Analysis Performed

* Data quality and duplicate checks
* Missing-value handling
* Control vs Treatment comparison
* Conversion rate analysis
* Revenue analysis
* Two-proportion statistical test
* Independent t-test
* Chi-square test
* Effect size and confidence interval analysis

## Tableau Dashboard

The Tableau dashboard presents:

* Total Users
* Total Conversions
* Conversion Rate
* Total Revenue
* Control vs Treatment Conversion
* Revenue by Group
* Conversion Rate by Device
* Conversion Rate by Region

## Key Result

The Treatment group did not show a statistically significant improvement in conversion rate compared with the Control group in this sample.

## Conclusion

The analysis demonstrates how statistical testing can support data-driven decisions by distinguishing meaningful differences from random variation.
